# Mándanos tu hoyo

Mapa público de los hoyos denunciados por vecinos de Peñalolén en la campaña "Mándanos tu hoyo" y de su estado de reparación.

- `index.html`: la página.
- `data/hoyos.js`: datos públicos (dirección, gravedad, estado, ubicación). No contiene datos personales.
- `data/calles.js`: calles de Peñalolén. Datos © colaboradores de OpenStreetMap (ODbL).
- `tools/`: scripts de actualización.
